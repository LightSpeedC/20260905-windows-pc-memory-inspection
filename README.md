# プロセスメモリ調査ツール

Windows PC の全プロセスのメモリ使用状況を定期的に調べ、HTML レポートを残す

> 📅 作成: 2026-09-15 / 更新: 2026-09-15

## これは何か

Windows PC 上で動いている全プロセスのメモリ使用量・起動時刻・親子関係を調べ、HTML のレポートとして `logs/` に残すツールである。タスクスケジューラに登録し、6 時間ごとに自動で記録する。

## 対象

- Windows PowerShell 5.1 が動く Windows 10 / 11
- subst で割り当てたドライブ上に置いたプロジェクトフォルダでの運用を前提にする

## 構成

| フォルダ | 内容 |
|---|---|
| `tools/80_ops/` | 調査本体（`inspect-process-memory.ps1`）・タスク登録・レポート修正用のスクリプト |
| `tools/40_test/` | テストの実行ランチャー |
| `tests/` | テスト本体（伏せ字処理の回帰テスト） |
| `logs/` | 調査結果の HTML レポート（Git 管理外） |
| `notes/` | 計画・課題などの管理資料 |
